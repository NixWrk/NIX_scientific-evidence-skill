# Отчёт о подготовке рукописи EXP-0024

## Итог

Подготовлена русскоязычная статья объёмом 3909 слов без рисунков, с оформлением
по научным разделам. В основной текст включены обзор литературы, цель, задачи,
описание данных и методов, положительные и отрицательные результаты, разбор
причин, ограничения и заключение.

Основной научный вывод сохранён без усиления: отдельные численные и синтетические
компоненты прошли проверку, но валидированная индивидуальная геометрия выдоха и
биологически интерпретируемая карта изменения полного пути через грудную стенку
по имеющимся данным не получены.

## Что проверено в исходном исследовании

1. Состав данных и канонический статус сверены с `PROJECT_STATUS.md`,
   `MEASUREMENT_MODEL.md` и журналом решений исходного репозитория.
2. Для чисел использованы зафиксированные таблицы и сводки регистрации, S1.0,
   S1.1, S1.2, J1.0–J1.2, W1, W2, R1–R3 и E1.
3. Для каждого типа отрицательного результата сохранена установленная причина:
   дефект эталонного фантома, растровая дискретизация, ограничение представления,
   неидентифицируемость функции потерь, неоднозначность анатомического якоря либо
   артефакт системы координат.
4. Литературный раздел ограничен двумя уже существовавшими локальными обзорами:
   19 записей по дыхательной геометрии и 8 публикаций по УЗИ межрёберной области.
5. Утверждение об отсутствии полноразмерной карты сформулировано только для
   предоставленного восьмипубликационного корпуса.

## Изменения скилла

Для режима рукописи введены два обязательных параметра:

- `figure_mode`: `with_figures` или `without_figures`;
- `formatting_mode`: `journal_example` или `section_only`.

Структурный валидатор отклоняет рукопись без этих полей. Режим
`journal_example` дополнительно требует идентификатор образца и сохранённой
карточки паттернов. Добавлены инструкция по извлечению паттернов, шаблон карточки
и каталог для их версионируемого хранения. Карточка содержит происхождение,
хеш образца, наблюдаемые особенности и явно ненаблюдавшиеся элементы. Она
поддерживает оформление, но не считается источником научных утверждений.

Для текущей задачи зафиксированы `without_figures` и `section_only`. Образец
журнала не применялся, поэтому карточка журнальных паттернов не создавалась.

## Ограничения результата

- Zotero MCP был недоступен во время выполнения задачи. Текущий состав
  подколлекций не проверен; использованы датированные локальные обзоры из
  исходного репозитория.
- Для восьми УЗ-публикаций в исходном обзоре полные библиографические названия не
  приведены. В списке литературы сохранены только доступные авторская группа,
  журнал, год и DOI; отсутствующие поля не реконструированы.
- Проверка русского языка является эвристической и дополнена ручной редактурой,
  но не заменяет научного и литературного редактирования человеком.
- Статья не адаптирована к конкретному журналу и не содержит рисунков в
  соответствии с условиями задачи.
