# EXP-0022 — прямой и evidence-first литобзор УЗИ межрёберных мышц

## Вопрос обзора

Что публикации из фиксированной подколлекции Zotero показывают о методах УЗИ
межрёберных мышц и прилежащих тканей, изменениях при дыхании,
воспроизводимости измерений и допустимой клинической интерпретации результатов?

## Корпус

Zotero user library `0`, путь коллекций:

```text
Калмыков
→ Изменение анатомии во время дыхания
→ УЗИ межрёберных мышц и расстояния плевра-кожа
```

Collection key: `TE9MV9FY`.

В коллекции девять объектов. В научный корпус включены восемь journal articles.
Служебный document `00. анализ` (`AK6G7KIC`) исключён до чтения, чтобы готовая
интерпретация пользователя не влияла на обе ветки.

## Сравниваемые условия

1. `direct`: текущий Codex-агент читает метаданные и доступные полные тексты и
   пишет обычный narrative review без загрузки файлов нового скилла в этой фазе.
2. `skill`: тот же агент обрабатывает тот же замороженный корпус по
   `scientific-evidence-workflow`, строит evidence bundle до связного текста и
   валидирует claim–evidence links.

Это парная неслепая ablation-проверка. Агент является автором скилла и уже знает
его общие принципы, поэтому разница не оценивает независимую генерализацию и не
может считаться слепым benchmark.

## Ограничения выполнения

- новые научные источники не добавляются;
- внешние model API и веб-поиск не используются;
- Zotero используется только для чтения;
- обе версии получают одинаковый вопрос и одинаковые восемь публикаций;
- ретрагированные работы не используются как положительные доказательства;
- сравниваются полнота, точность чисел, границы выводов, работа с конфликтами и
  трассируемость к Zotero item/section/table.
