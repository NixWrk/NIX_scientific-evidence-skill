# EXP-0002 — результат

Дата: 30 июля 2026 года.

## Результат

Для первого содержательного теста выбраны два workflow:

1. `literature-triage-matrix` — после локального профиля, запрещающего знания модели, DOI lookup и любые внешние материалы;
2. `academic-writing-skills` — для аудита «утверждение → доказательство» и последующего написания рукописи из замороженных результатов.

Они представлены обычными `SKILL.md` и не требуют отдельного облачного LLM. Первый кандидат нуждается в небольшом offline-профиле; второй допускается только с отключёнными необязательными внешними проверками.

Статический прогон по реальным каталогам дал следующие результаты:

| Skill | Строк | Формат | Сигналы политики в основном `SKILL.md` |
|---|---:|---|---|
| `literature-triage-matrix` | 128 | pass | network: 1; state mutation: 2 |
| `paper-summarize` | 107 | pass | external model: 4; state mutation: 6 |
| `academic-writing-skills` | 301 | pass | 0 |
| `academic-research-suite` | 329 | pass | external model: 18; network: 3 |

## Отсев

- `paper-summarize` связан с LLM CLI, структурой research-hub и записью заметок Zotero;
- `academic-paper-review` требует web-поиск в обязательной фазе;
- полный `academic-research-suite` слишком велик и включает несоответствующие политике ветви;
- `scientific-agent-skills/literature-review` построен вокруг расширения корпуса внешними сервисами.

Эти наборы не допускаются к обработке Zotero-корпуса в исходном виде.

## Ограничение проверки

Официальный `skills-ref` из спецификации Agent Skills не запускался: в текущем Python-окружении отсутствует `strictyaml`. Локальный `tools/audit_skill.py` без внешних зависимостей проверяет обязательные поля и правила имени, размер метаданных, наличие тела инструкции и сигналы запрещённых возможностей. Содержательный policy-вердикт выполнен вручную по основному `SKILL.md` и относящимся к запуску указаниям; перед каждым содержательным тестом обязательные reference-файлы проверяются отдельно.

## Следующий эксперимент

Сначала нужно сравнить прямой разбор уже имеющихся публикаций с `literature-triage-matrix` на одном и том же замороженном наборе HTML. Затем та же таблица доказательств станет входом для `academic-writing-skills`; это исключит смешение качества анализа литературы с качеством научного письма.
