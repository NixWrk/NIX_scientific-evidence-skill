# Offline-профиль `scientific-critical-thinking`

Этот профиль имеет приоритет над необязательными ветвями исходного skill.

1. Единственный источник фактов — указанная замороженная матрица.
2. Запрещены поиск, внешние справочные материалы и знания модели о статьях.
3. Запрещены OpenRouter, `scientific-schematics` и любые рисунки.
4. Ветки планирования нового исследования и улучшения будущего дизайна не
   выполняются: результат должен оставаться критическим Q&A.
5. Любое существенное фактическое положение получает исходный `block_id`, уже
   присутствующий во входной матрице.
6. Если матрица не содержит сведений для формальной GRADE/RoB-оценки, рейтинг
   не присваивается.
7. Запись разрешена только в каталоге `EXP-0005`.
