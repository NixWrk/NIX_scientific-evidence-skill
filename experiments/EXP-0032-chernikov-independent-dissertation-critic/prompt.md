# Blind critic prompt

Провести независимый critic-run полной кандидатской диссертации Р. С.
Черникова «Модели и алгоритмы оценки работоспособности телекоммуникационной
сети централизованной охраны объектов» (2023).

Разрешено:

- полный PDF по официальному URL;
- skills/scientific-evidence-workflow/SKILL.md;
- только необходимые reference-файлы этого скилла.

Запрещено до сохранения raw-отчёта:

- читать experiments, work-patterns, reading-logs, агрегаты pattern memory,
  официальные отзывы и ожидаемые замечания;
- добавлять внешние научные источники;
- выдумывать нормативный профиль;
- считать Word единственным или обязательным представлением.

Приоритет проверки: логика, научные формулировки, повествование, внутренняя
согласованность чисел и выводов, соответствие жанровым правилам выбранного
скилла. Для каждого существенного замечания дать PDF-страницу, наблюдение,
обоснование, границу проверенного и действие. Непроверенное помечать
not_assessed. Сохранить raw Markdown и JSON-манифест, не изменяя
отслеживаемые файлы.
