# EXP-0012 — результат

## Вердикт

`out_of_scope`.

Кандидат имеет сильные правила сохранения исходного содержания: запрещено
добавлять факты, результаты, данные и цитаты; уравнения, ключи цитирования,
переменные и численные результаты должны сохраняться; при анализе референсных
статей запрещены цитирование и пересказ их научного содержания. Перед правкой
рукописи предусмотрено подтверждение человеком. Лицензия — MIT, исполняемых
скриптов и обязательной внешней LLM нет.

## Почему corpus run не выполнялся

Главный workflow нельзя отделить от публикационной адаптации. Его обязательная
Phase 1 строит карточки стиля отдельных журнальных статей, агрегированный профиль
«культуры журнала» и новый `dynamic_writing_skill.md`. Phase 2 затем ставит каждому
абзацу `journal match score`, классифицирует проблемы как блокирующие принятие и
оптимизирует текст под целевое издание.

Эти промежуточные и оценочные результаты не являются вопросом/ответом по корпусу,
литературным обзором или нейтральной итоговой статьёй. Самостоятельного режима
правки, который пропускает Phase 1, в skill нет. Поэтому предоставленные
публикации и рукопись кандидату не передавались.

## Переносимость

В репозитории skill лежит в каталоге `skill`, поэтому прямой аудит даёт mismatch с
`name: journal-adapt`. После документированной установки в каталог
`journal-adapt` формат проходит. MinerU требуется только для PDF; Markdown и текст
можно использовать без него. Штатных тестов нет.

## Решение

Не включать кандидат в рабочий набор и не создавать для него offline-профиль.
Полезные запреты на изменение фактов уже присутствуют в более универсальном и
прошедшем содержательный тест YSLAB `manuscript-writing`, которому не требуется
журнальный style-corpus или publication-fit scoring.
