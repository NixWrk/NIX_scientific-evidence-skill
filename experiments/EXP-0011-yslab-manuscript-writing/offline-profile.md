# Offline evidence profile

Исходный skill уже запрещает выдумывать факты, числа, механизмы, цитаты, novelty и
литературный контекст. Для benchmark добавляются только следующие ограничения:

1. Проверка выполняется исключительно по предоставленному корпусу. Недоступные
   материалы помечаются `Needs Verification`; сеть и память модели не используются
   для заполнения пробелов.
2. Каждое крупное проверяемое утверждение получает точный локатор исходного
   HTML/PDF. Свободная citation placeholder не считается доказательством.
3. Неподдержанное утверждение ослабляется, удаляется или остаётся помеченным; не
   предлагается проектирование нового исследования.
4. Результат записывается только в каталог эксперимента. Исходная публикация и
   записи Zotero не изменяются.
5. Сеть, внешние LLM/API и субагенты во время обработки корпуса запрещены. Роль
   модели выполняет текущий Codex-агент либо локальная LLM.
