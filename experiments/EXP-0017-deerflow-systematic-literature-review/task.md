# EXP-0017 — DeerFlow systematic-literature-review

## Задача

Проверить scope, переносимость и локально исполняемые части
`skills/public/systematic-literature-review` до доступа к научному корпусу.

## Стоп-критерии

Corpus run запрещён, если основной workflow:

- сам ищет или добавляет публикации;
- требует API/сеть во время обработки;
- требует платформенную оркестрацию вместо текущего Codex/local LLM;
- работает по abstract вместо предоставленного полного HTML;
- не сохраняет локаторы источников до итоговых тезисов.

Локально разрешены только чтение исходников, статический аудит, компиляция и
pure-function smoke-tests без сетевого вызова.
