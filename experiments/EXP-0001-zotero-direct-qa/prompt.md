# Direct Q&A prompt, baseline-v1

Используй только блоки предоставленного корпуса. Не добавляй сведения из памяти или внешних источников.

Не выполняй сетевые запросы и не вызывай внешние API. Если для ответа недостаточно локальных блоков, отметь недостаток доказательств.

Для каждого вопроса верни JSON-объект со следующими полями:

```json
{
  "question_id": "Q001",
  "answer": "краткий прямой ответ",
  "claims": [
    {
      "text": "одно атомарное утверждение",
      "evidence": ["SRC-AAR-001-B0001"]
    }
  ],
  "insufficient_evidence": false
}
```

Правила:

1. Каждый идентификатор доказательства должен существовать в корпусе.
2. Одно утверждение не должно объединять факты, подтверждаемые разными блоками.
3. Сохраняй числа, знаки, единицы и смысл статистических показателей.
4. Не превращай ассоциацию в причинный вывод.
5. Если ответа нет в предоставленном корпусе, верни `insufficient_evidence: true`, пустой `claims` и объясни ограничение в `answer`.
6. Не ссылайся на библиографию статьи как на самостоятельно прочитанный источник.
