# EXP-0001: Direct Q&A over Zotero source HTML

## Цель

Установить минимальное качество прямых ответов по полным текстам, полученным из одной заранее заданной коллекции Zotero.

## Корпус

- Библиотека: локальная личная библиотека Zotero (`userID 0`).
- Коллекция: `ААР` (`HE2FL89L`).
- Размер: 8 публикаций.
- У каждой записи обнаружены исходный HTML, русский HTML и PDF.
- В этом эксперименте используется только исходный HTML.

## Сравниваемые варианты

1. `direct-zotero-html`: ответ непосредственно по нормализованным блокам HTML.
2. Evidence-first вариант будет отдельным экспериментом, чтобы не смешивать конфигурации.

## Формат ответа

Для каждого вопроса система должна вернуть:

- краткий ответ;
- атомарные утверждения;
- `source_id` и `block_id` для каждого утверждения;
- сообщение о недостатке данных, если ответа нет в корпусе.

## Критические ошибки

- ссылка на источник вне восьми элементов корпуса;
- несуществующий `block_id`;
- фрагмент не поддерживает утверждение;
- изменение числа или единицы;
- уверенный ответ при отсутствии доказательств.

## Хранение

Нормализованный полный текст сохраняется под `runs/EXP-0001/` и не коммитится. В Git хранятся только контрольные хэши, метаданные, короткие эталонные фрагменты и результаты аудита.
