# EXP-0001 — отчёт о подготовке

## Статус

Эксперимент готов к изолированному запуску. Оценка модели ещё не выполнялась.

Запуск из текущего контекста не считается допустимым benchmark: при составлении эталона использовались блоки полного текста, поэтому runner должен работать в отдельном процессе без доступа к `gold.jsonl`.

## Найденные особенности данных

- HTML существенно больше извлечённого текста из-за вёрстки и встроенных ресурсов.
- Иерархия заголовков неоднородна: уровни нельзя считать семантически корректными без дополнительной нормализации.
- В таблицах со сложными объединёнными заголовками возможна потеря структуры при плоском извлечении.
- Некоторые подписи представлены одновременно как `figcaption` и обычный абзац.
- У записи `KLUN4GNP` в ответе Zotero MCP отсутствовал список авторов, хотя полный текст доступен.
- В исходных статьях встречаются потенциально ошибочные или неоднозначные числа; нормализатор обязан сохранять их буквально, а не исправлять без отдельного аудита.

## Следующий шаг

Изолированный runner получает только:

1. `prompt.md`;
2. вопросы из `gold.jsonl` без полей `expected_facts`, `evidence` и `answerable`;
3. нормализованные документы из локального `runs/EXP-0001/normalized/`.

После генерации отдельный evaluator сопоставляет ответы с полным `gold.jsonl` и формирует `audit.json`.

## Состояние runner

- Изолированный пакет сформирован без gold-ответов.
- Локальные Ollama и LM Studio не обнаружены.
- Обычный запуск `codex exec` не прошёл TLS/сетевое соединение.
- Запуск с внешним сетевым доступом не выполнялся: для передачи локального Zotero-корпуса внешней модели требуется отдельное явное разрешение пользователя.
- Результат baseline пока отсутствует; подставлять ответы из контекста составления gold запрещено из-за утечки эталона.
