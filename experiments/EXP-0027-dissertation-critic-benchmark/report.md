# EXP-0027 — deterministic dissertation-critic benchmark scaffold

Status: `passed` for the committed synthetic smoke records. The runner is a
measurement scaffold; it does not call an LLM, network, subprocess, or Word
automation API.

The experiment declares all four PSES-DISS-001 stages:

- regression — one known citation finding;
- mutation — one controlled causal-strengthening finding;
- clean control — one unchanged fragment with no gold findings;
- holdout — one independent-style fixture with a recommendation.

The hidden gold and all fixture/baseline/skill output files are frozen by
SHA-256 in `manifest.yaml`. `report/status.json` is generated by
`skills/dissertation-formatting-and-apparatus/scripts/run_dissertation_benchmark.py`
and records the full per-rule TP/FP/FN, locator, authority and classification
metrics for both baseline and skill profiles. The synthetic skill output has
3/3 true positives, 0 false positives and 0 false negatives; the empty
baseline has 0/0/3.

The status is deliberately not a quality verdict for a production critic. A
real run must replace the `outputs/skill` records with an independently produced
journal while keeping the manifest, gold and fixtures unchanged.
