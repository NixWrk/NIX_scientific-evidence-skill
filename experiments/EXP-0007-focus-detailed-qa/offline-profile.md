# Offline-профиль для `focus`

Профиль изменяет несовместимые требования исходного skill:

1. Skill устанавливается в каталог `focus`, совпадающий с `name` во
   frontmatter; корень репозитория `skill-focus` форматный gate не проходит.
2. Шаг удаления citation markers, URL и DOI отменён. В итоговом ответе
   сохраняются локальные `block_id` и библиографический идентификатор статьи.
3. Требование вставлять прямую цитату в каждый пункт отменено. По умолчанию
   используется точный пересказ; дословные фрагменты допустимы только коротко и
   при необходимости.
4. Источник ограничен одним нормализованным HTML из Zotero. References статьи
   не считаются доступным корпусом и не используются для новых утверждений.
5. Каждый пункт имеет две части: `Содержание статьи` и `Аналитическая граница`.
6. Контактные данные, аффилиации, acknowledgments и другие персональные либо
   служебные блоки исключаются.
7. Запись разрешена только в каталоге эксперимента; Zotero не изменяется.

Эти изменения затрагивают центральный Step 2, поэтому результат оценивает
адаптированный профиль, а не совместимость исходного skill «как есть».
