# EXP-0026 — результат локального модельного прогона

Прогон состоялся 17 августа 2026 года через LM Studio CLI на локальной
`qwen/qwen3.5-9b@q4_k_m`. Сеть и внешние model API не использовались. Модель
получила ограниченный plain-text packet из навыка, режима Q&A, доказательного
контракта, задачи и ранее валидированного bundle EXP-0021.

## Результат первого прохода

Модель правильно отделила выполнимость процесса от клинической эффективности,
сохранила исходный корпус, основные значения и локаторы. Результат нельзя было
выпустить без проверки из-за четырёх ошибок:

1. медиана превратилась в «средний балл»;
2. в русский текст попал повреждённый фрагмент `контакт混杂рованы`;
3. `CL-004` был помещён в колонку доказательств;
4. модель заявила о языковой проверке, которая фактически не запускалась.

Вердикт первого прохода — `fail`.

## Результат второго прохода

Отдельный evidence-and-language pass исправил все четыре критические ошибки:
восстановил медиану, удалил повреждённый фрагмент, развёл claim и evidence IDs
и заменил ложное заявление о проверке описанием модельной самопроверки.

Остались замечания: опечатка `EV-07`, предположение о доступности полного
текста через host interface, неудачная метафора «вкладка» и пять английских
статусов в русской таблице. Детерминированный языковой аудит дал 11 ошибок и
одно предупреждение для первого прохода, пять ошибок — для второго. Поэтому
второй результат также нельзя считать готовым к автоматическому выпуску.

## Вывод для навыка

Статическая переносимость подтверждена реальным запуском: локальная модель
следует plain-text contract, не требует MCP или function calling и способна
исправить собственную научно значимую ошибку в отдельном проходе. Однопроходный
выпуск не подтверждён.

Для локальной модели обязательны:

- раздельные evidence и language passes;
- буквальная сверка типа статистики, числа, единицы и причинной силы;
- детерминированная проверка локаторов и русского языкового профиля;
- ручная семантическая проверка перед выпуском;
- validation disclosure, составленный host, а не моделью.

Итоговый вердикт — `partial_pass_two_pass_and_host_gate_required`.
