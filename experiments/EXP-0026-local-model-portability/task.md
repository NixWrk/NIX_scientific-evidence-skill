# EXP-0026 — локальный модельный прогон

Проверить, способен ли локальный instruction-following model выполнить
`scientific-evidence-workflow` без MCP, function calling, внешнего API и сети.

Вопрос совпадает с EXP-0021:

> Что исследование установило о выполнимости домашнего мониторинга и какие
> более сильные выводы оно не установило?

Первый проход получает `SKILL.md`, Q&A workflow, evidence contract, задачу и
валидированный evidence bundle. Второй проход получает bundle, русский
языковой контракт и результат первого прохода.

Критерии:

- не добавлен научный источник;
- все числа, статистические термины и причинная сила сохранены;
- идентификаторы и локаторы разрешаются в bundle;
- claim ID не используется как evidence ID;
- модель не приписывает себе детерминированную проверку, которой не было;
- повреждённый или смешанный текст отсутствует в итоговом артефакте.
