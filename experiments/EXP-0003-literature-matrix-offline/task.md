# EXP-0003 — offline literature matrix

## Цель

Проверить, помогает ли `literature-triage-matrix` сравнивать уже предоставленные публикации по вопросу, методу, данным, выводам и ограничениям без расширения корпуса.

## Подкорпус

Три связанные публикации о торакальном или лёгочном биоимпедансе при сердечной недостаточности:

- `SRC-AAR-001` — обзор возможностей дистанционного мониторинга;
- `SRC-AAR-002` — 30-дневное домашнее наблюдение после выписки;
- `SRC-AAR-003` — сравнение торакального импеданса с рентгенографией грудной клетки.

## Критерии

- все фактические ячейки поддержаны локальными `block_id`;
- feasibility не подменяется clinical efficacy;
- противоречащие числа отмечаются как конфликт;
- рекомендации по роли источника отделены от сообщаемых авторами результатов;
- внешние материалы отсутствуют.
