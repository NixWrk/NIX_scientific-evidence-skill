# Offline-профиль

Применяется workflow `literature-triage-matrix` со следующими обязательными переопределениями:

1. Использовать только предоставленные нормализованные блоки Zotero HTML.
2. Не использовать память модели как источник фактов.
3. Не выполнять DOI lookup, web-поиск и любые сетевые запросы.
4. Не добавлять публикации и не записывать результаты в Zotero.
5. Для проверяемых утверждений приводить существующие `block_id`.
6. Неизвестные значения обозначать явно; конфликты между частями статьи не разрешать догадкой.
7. `Relevance` и `Use as` считать аналитической рекомендацией, а не фактом из публикации.
