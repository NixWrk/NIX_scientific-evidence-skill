# Сравнение EXP-0007 и EXP-0008

Оба адаптированных профиля получили один нормализованный HTML и не имели
доступа к другим источникам.

| Критерий | FOCUS, EXP-0007 | `paper-reader`, EXP-0008 |
|---|---|---|
| Организация | 20 последовательных пунктов по ходу статьи | Фиксированные разделы заметки |
| Трассировка | `block_id` добавлены профилем | `block_id` добавлены профилем |
| Разделение факта и оценки | Явно в каждом пункте | Отдельный `Analytical Boundary` и оговорки внутри разделов |
| Полнота процедур | Выше: отдельно разобраны inclusion/exclusion, ethics и clinical measures | Компактнее, но сохраняет основные дизайн, измерения и анализ |
| Риск исходного skill | Удаляет ссылки, требует direct quotes | Разрешает Agent, abstract-only fallback и запись в общие notes/index |
| Пригодность без адаптации | Нет | Нет |

FOCUS лучше подходит для исчерпывающего ответа по одной статье, а схема
`paper-reader` — для компактной унифицированной карточки. Это наблюдение по
одному документу, не общий рейтинг skills.
