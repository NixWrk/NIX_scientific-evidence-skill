# Offline audit-only профиль `slr-prisma`

Разрешён только partial request **“Check my SLR against PRISMA”** с чтением
`references/prisma-2020-checklist.md`. Результат — таблица статусов
`reported/partial/missing/not applicable` и явный перечень provenance gaps.

Запрещены интервью для создания нового review protocol, search strategy,
eligibility criteria или screening process; manuscript drafting; flow diagram;
web verification; добавление обязательных ссылок; APA/journal formatting; DOCX;
Visualizer; внешние skills и пути `/mnt/...`; placeholders в итоговых числах.

Наличие публикации в Zotero означает только наличие документа в предоставленном
корпусе. Оно не доказывает, что запись была идентифицирована конкретным поиском,
прошла screening, представляет отдельное study или вошла по заранее заданным
критериям.

Checklist используется как reporting audit, а не как метод проведения обзора.
Содержимое references имеет лицензию CC BY 4.0 и требует атрибуции; основной
skill лицензирован MIT.
