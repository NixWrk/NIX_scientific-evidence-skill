# PRISMA 2020 audit для EXP-0003

## Краткий вывод

`literature_matrix.md` — трассируемое narrative comparison трёх публикаций, но
не отчёт о систематическом обзоре. Отсутствуют протокол поиска и отбора, поэтому
PRISMA flow diagram и утверждение «systematic review» недопустимы.

## Решение

Не переименовывать EXP-0003 в systematic review, не создавать PRISMA flow и не
заполнять отсутствующие пункты предположениями. После получения реального
protocol/search log/screening export этот же профиль можно повторно использовать
для reporting audit уже проведённого обзора.
