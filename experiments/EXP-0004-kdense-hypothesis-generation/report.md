# EXP-0004 — результат

## Вердикт

`out_of_scope`.

Заявленный local-only контракт скриптов в целом подтверждён: в рабочих
скриптах не найдены сетевые импорты, вызовы внешних моделей или subprocess.
`SKILL.md` проходит проверяемое подмножество формата Agent Skills, имеет 264
строки и SHA-256
`e18e00ed9bd98939f57254b627b6db52c276f7c2f0ae2eac52da89fdd896ad49`.
Репозиторий и сам skill объявлены под лицензией MIT.

## Почему исходная оценка A не подтверждена

Шаг 4 обязательного workflow требует выполнять поиск до
литературно-зависимых утверждений. Это нарушает правило замкнутого
предоставленного корпуса. Его можно было бы заменить offline-профилем, но
главный результат skill — гипотезы, прогнозы и план исследования — всё равно
не относится к трём выходам этого репозитория.

Поэтому публикации skill не передавались, а content smoke-тест намеренно
пропущен. Это не оценка научного качества skill; это отказ по области проекта.

## Штатные тесты

На commit `ab2f84ab10597c59fac186ecda6d5edd5dcc8b92` команда автора завершилась как
`26 passed, 1 failed`. Единственный сбой проверяет POSIX-права `0600`: в Windows
созданный временный JSON сообщил mode `0666`. Остальные тесты, включая
статические запреты сети, динамического кода, subprocess и чтения credential
environment variables, прошли.

## Решение

- не скачивать и не устанавливать skill в рабочий набор;
- не адаптировать его для корпусного benchmark;
- продолжить этот же репозиторий с `scientific-critical-thinking` и
  `scholar-evaluation`, поскольку их результат может использоваться для
  критического Q&A, литературного обзора или аудита рукописи.
