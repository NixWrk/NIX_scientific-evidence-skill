# Stored journal patterns

Place versioned JSON records extracted from user-supplied journal examples in
this directory. Use `../../assets/journal-pattern.template.json` as the
scaffold and follow `../journal-pattern-memory.md`.

No journal pattern is assumed by default. An empty directory means that only
section-based manuscript formatting is available.

## Available records

- `JOURNAL-PATTERN-BMRE-001.json`: one user-supplied DOCX example attributed to
  «Биомедицинская радиоэлектроника» (БМРЭ); the record contains explicit
  warnings about inconsistent editorial metadata in that file.
