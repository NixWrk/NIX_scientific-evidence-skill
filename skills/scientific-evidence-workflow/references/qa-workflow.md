# Q&A workflow

## Input

Require a question, an explicit source scope, and the desired answer depth.
Record whether the user wants a direct, comparative, or critical answer.

## Procedure

1. Rewrite the question into atomic subquestions without changing its meaning.
2. Identify which supplied sources can answer each subquestion.
3. Extract atomic evidence with stable locators.
4. Record contrary evidence, design limits, and unresolved conflicts.
5. Draft the direct answer from the evidence records.
6. Build the claim ledger for every material sentence.
7. Check all numbers, directions, groups, units, and time points.
8. State that the supplied corpus is insufficient when support is absent.

## Output order

1. Direct answer.
2. Evidence by subquestion or claim.
3. Conflicts and limitations.
4. What cannot be concluded.
5. Compact claim–evidence ledger.

Do not turn a future-work statement into a result. Do not convert an association
into a cause or a feasibility observation into clinical effectiveness.

Use `assets/qa-output.template.md` when a file artifact is requested.
