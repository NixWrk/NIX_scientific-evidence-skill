# Библиографические ссылки и список литературы по ГОСТ

Применяй этот контракт к русскоязычному литературному обзору, микрообзору и
обзорной главе диссертации. Он задаёт оформление библиографического аппарата,
но не меняет состав корпуса и не создаёт отсутствующие сведения.

## Нормативная основа

- библиографические ссылки — ГОСТ Р 7.0.5–2008;
- библиографические описания — ГОСТ Р 7.0.100–2018;
- для диссертации ГОСТ Р 7.0.11–2011 прямо отсылает ссылки в тексте к
  ГОСТ Р 7.0.5–2008.

Перед нормативной проверкой используй карточки
`NORM-GOST-R-7.0.5-2008-001`, `NORM-GOST-R-7.0.100-2018-001` и, для
диссертации, `NORM-GOST-R-7.0.11-2011-001`. Не превращай один допустимый
вариант стандарта в единственно возможный: выбери вид ссылок и применяй его
единообразно во всём документе.

## Название публикации

Воспроизводи основное заглавие в форме, последовательности и с пунктуацией
источника. Не переводи название публикации и не
подменяй его русским пересказом. Официальное параллельное заглавие допускается
только тогда, когда оно приведено в самой публикации или другой предписанной
области источника; отделяй его знаком равенства. Самостоятельно составленный
перевод в библиографическую запись не добавляй.

Не сокращай слова в заглавии, если сокращение отсутствует в источнике. Не
исправляй регистр, пунктуацию и порядок слов ради единообразия списка. Если
метаданные Zotero расходятся с публикацией, основным считается заглавие,
проверенное по самой публикации; расхождение фиксируется отдельно.

## Ссылка в тексте

Выбери один допустимый вид ссылок: внутритекстовый, подстрочный или
затекстовый. Для нумерованных затекстовых ссылок используй единообразную
нумерацию и номера в квадратных скобках. При ссылке на конкретный фрагмент
указывай страницу после номера записи. Несколько ссылок в одной отсылке
разделяй точкой с запятой, если выбранная форма требует комплексной ссылки.

Ссылка должна позволять идентифицировать и найти документ. Не создавай ссылку
на аннотацию, заметку или карточку вместо публикации. При цитировании по
вторичному источнику помечай это по ГОСТ и указывай источник заимствования.

## Библиографическая запись

Для каждого типа источника приводи применимые и доступные элементы описания:
авторов, точное заглавие, сведения об ответственности, источник публикации,
год, том, выпуск, страницы и идентификатор ресурса. Для сетевого ресурса
сохраняй URL и дату обращения, когда они требуются выбранной формой. DOI не
заменяет остальные сведения, необходимые для идентификации записи.

Не восстанавливай отсутствующего автора, выпуск, страницы, издателя, DOI или
дату по памяти. Помечай неполноту записи и запрашивай источник, если без поля
документ нельзя надёжно идентифицировать.

## Проверка перед выпуском

1. Каждая отсылка разрешается в одну запись списка литературы.
2. Каждая запись списка литературы используется в тексте либо помечена как
   дополнительная библиография, если это предусмотрено заданием.
3. Название совпадает с публикацией и не переведено.
4. Вид и пунктуация ссылок единообразны.
5. Страница указана для дословной цитаты или отсылки к конкретному фрагменту.
6. Запись содержит достаточные сведения для поиска, а отсутствующие поля не
   выдуманы.
